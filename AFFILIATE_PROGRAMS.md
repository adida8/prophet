**Scope:** Prediction-market platforms (Kalshi, Polymarket, PredictIt, Manifold, Limitless, Myriad, SX Bet, Drift BET, Augur) + brokerages with event-contract products (Robinhood Event Contracts, Interactive Brokers ForecastEx).

For a comparison/oddschecker product, Polymarket is the monetization spine; Kalshi and SX Bet are the geography/category complements.

## Detailed Terms

### 1. Polymarket — STRONGEST FIT

| Field | Detail |
|---|---|
| **Formal program** | Yes — *Referral Program* (open) + *Partner Program* via Dub.co (invite/apply) |
| **Commission (Referral)** | **30% of trading fees** from direct referrals + **10%** from indirect (second-tier) referrals — i.e. if you refer Alice and Alice refers Bob, you get 10% of Bob's fees too. Verified directly against [Polymarket Help Center](https://help.polymarket.com/en/articles/14174498-referral-program) |
| **Commission (Partner via Dub)** | Hybrid — click bounty + ~**$10 USDC per qualified referral** (first deposit) |
| **Attribution window** | **180 days from the referee's signup date** (subject to change without notice per Polymarket) |
| **Underlying fee base** | Variable: ~1.80% peak on crypto markets at 50¢, ~0.75% on sports, **0% on Geopolitical/World Events** (effective 2026-04-03). World Cup contracts likely fall under "sports" tier |
| **Payout** | **USDC, daily at midnight UTC, direct to wallet.** No minimum, unlimited cap |
| **Eligibility (Referral)** | Open to any user with $10,000+ lifetime trading volume |
| **Eligibility (Partner)** | Application-only; aimed at KOLs/creators |
| **Tracking** | polymarket.com/refer link; on-chain wallet attribution; Dub deeplinks for partners |
| **Geo restrictions** | US: blocked in AZ, IL, MA, MD, MI, MT, NV, OH. Internationally: 33+ countries blocked (OFAC + EU gambling enforcement + selective Asia) |
| **US status** | Live — relaunched Dec 2025 via QCX LLC d/b/a Polymarket US (CFTC DCM, acquired QCEX July 2025) |
| **Risk flags** | $10k volume gate for the referral program creates a chicken-and-egg problem; need to push referees to that threshold or focus on Partner track from day one |

### 2. Kalshi — REGULATORY WINNER, WEAK FORMAL TERMS

| Field | Detail |
|---|---|
| **Formal program** | No public self-serve affiliate program. Two mechanisms: (a) user-facing **Refer-a-Friend** ($25 credit each, $1k lifetime cap), (b) invite-only **Ambassador / Creator Program** (kalshi.com/ambassadors — bespoke grants, badges, comp deals) |
| **Commission** | Refer-a-Friend: flat **$25 trading credit** to referrer + $25 to referee (NOT cash — only profits earned from credits are withdrawable). Ambassador: negotiated |
| **Attribution** | Referral link or promo code at signup (no cookie/postback). Examples in market: GRINDERS, DEFI, CBSSPORTS — all $10 sign-up bonus codes |
| **Payout** | Trading credits only; auto-issued when referee completes trading requirement |
| **Eligibility** | US users only; international ineligible. Ambassador slots application-only and curated |
| **Geo restrictions** | US-only. State blocks: NV (sports/election/entertainment under court injunction); AZ, IL, MA, MD, MI, MT, NJ (won by Kalshi at 3rd Cir. Apr 2026), OH varying |
| **Caps** | **$1,000 lifetime referral cap per user** |
| **Recent changes** | **Feb 2026: Kalshi pulled all X affiliate badges** after X tightened gambling promo policy. Signals affiliate-policy fluidity — assume terms can change |
| **Risk flags** | Credit-not-cash payout makes formal program useless for a media business. Path to value is direct BD relationship as a comparison/data partner, not the public referral link. The X-badge yank also signals Kalshi is getting more conservative about affiliate noise |

## Cross-Cutting Risks & Decisions

**1. Attribution conflict — Kalshi vs Robinhood (US traffic).**
Both pay on signups. A user routed through Robinhood's Impact link will *not* trigger a Kalshi referral, even if they trade Kalshi-powered event contracts inside Robinhood. Pick one per piece of US content; default to Robinhood for "open an account" CTAs and Kalshi-direct only for users specifically wanting native Kalshi.

**2. Geo coverage gaps for World Cup.**
- Polymarket: blocked in 8 US states + 33+ countries
- Kalshi: US-only, NV blocked
- SX Bet / Myriad / Limitless: per-protocol ToS, generally more permissive internationally
**Recommendation:** Build Prophet's link-out logic to detect geo and surface the legal platform per region. SX Bet + Polymarket cover most of the world; Kalshi/Robinhood cover US.

**3. Affiliate-policy fluidity.**
Kalshi's Feb 2026 X-badge purge is a warning shot — affiliate terms in this space change fast as regulators move. Build affiliate links into a single config file (one place to swap), not hardcoded across components.

**4. KOL/Partner-tier negotiation > self-serve.**
The best terms are not on the public page. Polymarket Partner (Dub.co), Kalshi Ambassador, and Robinhood's creator desk all offer custom deals. For Prophet — pitch as "comparison/data partner driving qualified, intent-led traffic" rather than as a generic affiliate.

**5. Compliance surface.**
Promoting regulated event contracts requires (a) clear affiliate disclosure, (b) no misleading return claims, (c) geo-gating per platform ToS. Robinhood and IBKR Impact agreements have explicit financial-content rules. Prophet needs a standard disclosure footer + per-platform geo checks before any affiliate link fires.
